# Aether Impact

A GenLayer-powered Retroactive / Impact Funding Evaluation Engine. DAOs, foundations, and protocols run scalable, transparent impact evaluations using GenLayer Intelligent Contracts.

## Structure

- `frontend/` — Next.js 15 app (TypeScript, Tailwind, Framer Motion)
- `contracts/` — GenLayer Intelligent Contracts (Python)
- `prompts/` — LLM prompt templates for evaluation logic
